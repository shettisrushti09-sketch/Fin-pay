# FinPay – Digital Wallet and Cashback Platform

## Project Overview
FinPay is a digital wallet application designed to provide students with a convenient way to manage wallet balances, make payments, and receive cashback rewards.

## Technologies Used

### Backend
- Python
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication

### Frontend
- React
- Vite
- JavaScript
- CSS

## Main Features
- Student authentication
- Digital wallet management
- Wallet top-ups
- Payment transactions
- Merchant management
- Cashback rules and rewards
